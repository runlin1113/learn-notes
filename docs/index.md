# 凌润林的学习笔记 📚

> **记录学习 · 传播知识 · 开源协作**

这里是我一边学习、一边整理输出的地方。所有笔记以 Markdown 写作、以免费开放的网页形式发布——没有付费墙，也没有秘密。

!!! note "本站的三个目标"
    - **记录学习**：把学过的科目系统化整理，方便未来的自己快速回顾；
    - **传播知识**：让后来的人少走弯路，读到可直接借鉴的推导与总结；
    - **开源协作**：本站在 GitHub 上公开维护，欢迎任何人纠错、补充、共建。

---

## 快速开始

=== "🚀 我想快速浏览"
    直接用左侧导航或顶部标签，找到感兴趣的科目点进去即可。
    也可以按 ++f++ 或点击搜索框，全文检索任意关键词。

=== "✍️ 我想自己写笔记（本地）"
    1. 克隆仓库并安装依赖（只需一次）：
       ```bash
       pip install -r requirements.txt
       ```
    2. 本地实时预览：`note serve`，浏览器打开 `http://127.0.0.1:8000`
    3. 写完后一键发布：`note publish "本次更新说明"`

=== "🤝 我想参与贡献"
    纠错、补充、翻译都非常欢迎。请阅读「[贡献与开源](使用指南/贡献与开源.md)」，
    或直接到 [GitHub 仓库](https://github.com/runlin1113/learn-notes) 提 Issue / Pull Request。

!!! tip "想新增一个科目？"
    在 `docs/` 下新建一个文件夹（例如 `docs/计算机网络/`），再写一个 `index.md` 作为该科目的入口页，
    然后运行 `note new 计算机网络 主题名` 新建笔记即可——**无需修改任何配置文件**。
