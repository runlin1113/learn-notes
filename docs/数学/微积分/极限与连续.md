# 极限与连续

> 示例笔记：用于演示一篇笔记的写法。这是我学习微积分时整理的笔记，内容供参考。

## 1. 直觉：极限是什么

「当 $x$ 无限趋近于 $a$ 时，$f(x)$ 无限趋近于 $L$」，就记作：

$$
\lim_{x \to a} f(x) = L
$$

!!! note "通俗理解"
    极限描述的是「趋势」，不是「到达」。我们关心的是 $x$ 靠近 $a$ 时函数值的走向，
    与 $f(a)$ 本身取什么值无关。

## 2. 严谨定义（$\varepsilon$-$\delta$ 语言）

函数 $f$ 在 $x=a$ 的极限为 $L$，是指：对任意 $\varepsilon > 0$，都存在 $\delta > 0$，
使得当 $0 < |x - a| < \delta$ 时，有 $|f(x) - L| < \varepsilon$。

写成形式化的逻辑：

$$
\forall \varepsilon > 0,\ \exists \delta > 0,\quad
0 < |x-a| < \delta \ \Longrightarrow\ |f(x)-L| < \varepsilon
$$

## 3. 常见重要极限

| 极限 | 结果 |
|:--|:--|
| $\lim\limits_{x \to 0} \dfrac{\sin x}{x}$ | $1$ |
| $\lim\limits_{x \to 0} \dfrac{1 - \cos x}{x^2}$ | $\dfrac{1}{2}$ |
| $\lim\limits_{x \to \infty} \left(1 + \dfrac{1}{x}\right)^x$ | $e$ |
| $\lim\limits_{x \to 0} \dfrac{e^x - 1}{x}$ | $1$ |

## 4. 连续性

函数在 $x=a$ 处连续，需要同时满足：

1. $f(a)$ 有定义；
2. $\lim\limits_{x \to a} f(x)$ 存在；
3. $\lim\limits_{x \to a} f(x) = f(a)$。

这三个条件缺一不可。

!!! warning "易错点"
    分段函数的分段点处最容易「不连续」，判断时一定要逐一检查上面的三个条件。

## 5. 我的思考

??? tip "为什么要有 $\varepsilon$-$\delta$ 语言？"
    因为「无限趋近」是含糊的说法。$\varepsilon$-$\delta$ 定义把「要多近有多近」翻译成了
    **可以验证的数学命题**——无论你给出多小的误差 $\varepsilon$，我都能找到一个合适的 $\delta$ 满足条件。

??? question "练习：用定义证明 $\lim\limits_{x \to 2} (3x - 1) = 5$？"
    提示：取 $\delta = \varepsilon / 3$，当 $0<|x-2|<\delta$ 时，$|(3x-1)-5|=3|x-2|<3\delta=\varepsilon$。✓
