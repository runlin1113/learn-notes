# 贡献与开源

本站公开维护的初衷之一，就是传播**开源与协作**的精神：
知识不应该封闭在某个人的笔记里，而应该在反复的讨论、纠错与接力中越变越好。

## 你可以怎样参与

| 方式 | 适合 | 操作 |
|---|---|---|
| 提建议 / 报错 | 任何人 | 到仓库 [Issues](https://github.com/runlin1113/learn-notes/issues) 新建 Issue |
| 改错别字 / 小修改 | 想快速上手 | 网页版直接编辑，见下方「网页端改错」 |
| 补充内容 / 新笔记 | 想认真贡献 | Fork 仓库 → 写笔记 → Pull Request |
| 转载 / 二次创作 | 自媒体、课堂 | 遵守 CC BY-NC 4.0：署名 + 非商业即可 |

## 网页端改错（最快，无需装任何东西）

1. 打开你想修改的笔记页面，点击右上角 ✏️ **编辑此页** 铅笔图标；
2. 会跳转到 GitHub 的网页编辑器，改完点 **Commit changes**；
3. 选择 **Create a new branch and start a pull request**，填上修改说明，提交 PR。

作者看到 PR 后会 review 并合并，你的名字会出现在仓库贡献者列表里。

## 贡献一篇新笔记

1. 在 GitHub 上 **Fork** 本仓库；
2. 克隆到本地，按「[使用指南](index.md)」安装依赖；
3. 用 `note new` 新建笔记并认真写作（格式见「[Markdown 写作速查](Markdown-写作速查.md)」）；
4. 本地 `note serve` 预览确认无误；
5. `git push` 到你的仓库，然后向本仓库发起 Pull Request。

## 写作约定（请共同遵守）

- **内容真实**：不写占位符、不编造事实，引用务必注明出处；
- **注明日期与标签**：方便读者判断时效、按标签检索；
- **谦虚的表达**：学习笔记允许不确定，请用「我的理解」「待考证」等措辞标注存疑处；
- **尊重许可**：你的贡献将以 CC BY-NC 4.0（文字）发布。
