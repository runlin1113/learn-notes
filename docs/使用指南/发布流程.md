# 发布流程（GitHub Pages）

本站发布到 **GitHub Pages**。整个流程：`note publish` → 推送到 GitHub → GitHub Actions 自动构建并部署。

!!! success "本站已上线"
    线上地址：<https://runlin1113.github.io/learn-notes/>

## 一、首次部署（已完成）

本项目已在 2026-09 完成首次部署：公开仓库 `runlin1113/learn-notes`、GitHub Pages（源：GitHub Actions）、首次推送与开启全部就绪。以下步骤仅作为日后「换电脑 / 重新搭建」时的参考存档。

### 第 1 步：创建 GitHub 仓库

1. 打开 <https://github.com/new>；
2. Repository name 填 `learn-notes`；
3. 选择 **Public**（公开——本站的精神就是开放共享）；
4. 点 **Create repository**（不要勾选任何初始化文件）。

### 第 2 步：把本地代码推上去

在项目根目录执行（把 `yourname` 换成你的 GitHub 用户名）：

```bash
git init
git add .
git commit -m "初始提交：学习笔记站"
git branch -M main
git remote add origin https://github.com/yourname/learn-notes.git
git push -u origin main
```

### 第 3 步：开启 GitHub Pages

1. 进入仓库页面 → 顶部标签 **Settings**；
2. 左侧菜单找到 **Pages**；
3. 在 **Build and deployment** → **Source** 下拉框选择 **GitHub Actions**；
4. 之后每次推送到 `main`，`deploy.yml` 工作流会自动把站点发布出去。

### 第 4 步：访问你的站点

构建完成后（约 1 分钟），站点地址为：

```
https://yourname.github.io/learn-notes/
```

可以在仓库 **Actions** 标签页查看构建进度，绿色 ✓ 表示成功。

## 二、日常更新（你只需要做这一步）

写完笔记后，直接点击可视化后台的 **「发布」** 按钮，或在项目根目录执行：

```bash
note publish "更新说明：例如「新增 微积分·极限与连续」"
```

它会自动完成：构建检查 → 提交 → 推送到 GitHub。
约 1 分钟后，访问 <https://runlin1113.github.io/learn-notes/> 即可看到更新。

!!! tip "首次使用可视化后台发布"
    如果后台提示推送失败，先在项目根目录确认能正常 `git push`（凭据已存入系统凭据管理器，一般无需重复操作）。

## 三、常见问题

??? question "push 后站点没更新？"
    去仓库 **Actions** 页看是否有红色 ✗。
    常见原因：GitHub Pages 的 Source 还没设为 **GitHub Actions**（见首次部署第 3 步）。

??? question "想用自己的域名？"
    1. 购买域名后，在域名服务商处添加一条 CNAME 记录，指向 `runlin1113.github.io`；
    2. 在仓库 **Settings → Pages** 的 **Custom domain** 填你的域名并保存；
    3. 在 `docs/` 目录放一个 `CNAME` 文件，内容为你的域名（注意：不要带 `https://`）。
