# 使用指南

本站的核心设计理念：**你只负责写 Markdown，剩下的交给工具。**

你只需要掌握三个命令，就能完成「写笔记 → 预览 → 发布」的全部流程。

## 1. 安装（只需一次）

```bash
# 需要 Python 3.9+
pip install -r requirements.txt
```

## 2. 写笔记

!!! tip "推荐方式：用 note 命令一键新建"

    在项目根目录运行：

    ```bash
    note new 数学/微积分 极限与连续
    ```

    这会自动在 `docs/数学/微积分/` 下生成 `极限与连续.md`，
    并帮你写好文件头部（frontmatter），打开直接开写。

    如果只想建「科目入口页」（某科目/章节的 index），使用：

    ```bash
    note new 数学/线性代数 --topic
    ```

    也可以手动建：在 `docs/` 任意子目录放一个 `.md` 文件即可。
    **目录结构就是导航结构**——一个文件夹 = 一个科目/章节，一个文件 = 一篇笔记。

## 3. 本地预览

```bash
note serve
```

浏览器打开 <http://127.0.0.1:8000>，修改文件后页面会自动刷新，所见即所得。

## 4. 发布上线

```bash
note publish "本次更新：补充极限的性质"
```

该命令会自动执行：构建检查 → `git add` → `git commit` → `git push`。
推送后 GitHub Actions 会自动重新部署，约 1 分钟后线上更新完成。

!!! warning "首次发布前"
    第一次需要把仓库推到 GitHub 并开启 Pages，具体步骤见「[发布流程](发布流程.md)」。

## 常用命令速查

| 命令 | 作用 |
|---|---|
| `note new 科目/章节 笔记名` | 新建一篇笔记（自动带模板） |
| `note new 科目 --topic` | 新建科目/章节入口页 index.md |
| `note serve` | 本地实时预览 |
| `note build` | 只构建，不发布（检查是否有错误） |
| `note publish "说明"` | 构建 + 提交 + 推送，触发线上部署 |
| `note stat` | 统计各科目笔记数量 |

## 一页看完写作格式

- 一篇笔记 = 一个 `.md` 文件，顶部几行「文件头」写元信息（标题/日期/标签）；
- 正文用标准 Markdown，本站额外支持：**数学公式**、**代码高亮**、**提示框**、**多标签页** 等；

完整的功能演示与格式规范，见「[Markdown 写作速查](Markdown-写作速查.md)」。
