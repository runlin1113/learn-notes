# 线性回归（Linear Regression）

> 示例笔记：演示含代码与数学的笔记写法。

## 1. 问题设定

给定数据集 $\{(\boldsymbol{x}^{(i)}, y^{(i)})\}_{i=1}^{n}$，其中
$\boldsymbol{x} \in \mathbb{R}^{d}$ 是特征，$y \in \mathbb{R}$ 是标签。
线性回归假设标签与特征之间存在线性关系：

$$
\hat{y} = \boldsymbol{w}^{\top}\boldsymbol{x} + b
$$

其中 $\boldsymbol{w}$ 是权重，$b$ 是偏置。

## 2. 损失函数（均方误差 MSE）

我们用均方误差衡量预测与真实的差距，并希望最小化它：

$$
\mathcal{L}(\boldsymbol{w}, b) = \frac{1}{n} \sum_{i=1}^{n}
\left( \hat{y}^{(i)} - y^{(i)} \right)^2
$$

!!! note "为什么要除以 n？"
    除以样本数后，损失是「平均每个样本的误差」，与数据量无关，方便比较不同规模数据集上的损失。

## 3. 求解：梯度下降

损失对参数的梯度为：

$$
\frac{\partial \mathcal{L}}{\partial \boldsymbol{w}} =
\frac{2}{n}\sum_{i=1}^{n} \left(\hat{y}^{(i)} - y^{(i)}\right)\boldsymbol{x}^{(i)}
$$

参数更新规则（$\eta$ 为学习率）：

$$
\boldsymbol{w} \leftarrow \boldsymbol{w} - \eta\, \frac{\partial \mathcal{L}}{\partial \boldsymbol{w}}
$$

## 4. 代码实现（NumPy 版）

=== "从零实现"

    ```python
    import numpy as np

    def train(X, y, lr=0.01, epochs=1000):
        """X: (n, d), y: (n,)"""
        n, d = X.shape
        w = np.zeros(d)
        b = 0.0
        for _ in range(epochs):
            y_hat = X @ w + b
            grad_w = 2 / n * (X.T @ (y_hat - y))
            grad_b = 2 / n * (y_hat - y).sum()
            w -= lr * grad_w
            b -= lr * grad_b
        return w, b

    # 造一组线性数据做验证
    rng = np.random.default_rng(42)
    X = rng.uniform(-1, 1, (200, 1))
    w_true, b_true = 3.0, -1.0
    y = w_true * X[:, 0] + b_true + rng.normal(0, 0.1, 200)

    w, b = train(X, y)
    print(f"学到的 w={w[0]:.3f}（真值 3.0），b={b:.3f}（真值 -1.0）")
    ```

=== "sklearn 版"

    ```python
    from sklearn.linear_model import LinearRegression
    model = LinearRegression().fit(X, y)
    print(f"学到的 w={model.coef_[0]:.3f}，b={model.intercept_:.3f}")
    ```

## 5. 我的小结

!!! summary "要点回顾"
    1. 线性回归 = 「线性假设 + 均方误差 + 梯度下降」三件套；
    2. 损失函数是凸函数，因此梯度下降能找到全局最优（这是它与神经网络的重要区别）；
    3. 数据标准化（均值 0 方差 1）能显著加快收敛。

??? question "思考：如果特征之间存在强共线性会怎样？"
    最小二乘解 $\boldsymbol{w}^* = (\boldsymbol{X}^{\top}\boldsymbol{X})^{-1}\boldsymbol{X}^{\top}\boldsymbol{y}$
    中矩阵 $\boldsymbol{X}^{\top}\boldsymbol{X}$ 接近奇异，求逆不稳定 → 解方差很大。
    这也是 **岭回归（Ridge，加 L2 正则）** 存在的原因。
